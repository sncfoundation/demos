# 🎪 SNCF Demos

**Fun, working demos of the Sheet-Native Computing Foundation.**

Things that should not work on a spreadsheet, working on a spreadsheet.
A [Sheet-Native Computing Foundation](https://sncfoundation.github.io) project.

</div>

---

| Demo | What | Uses |
|------|------|------|
| [**sep3**](sep3/) | «И снова третье сентября» — a public, anyone-can-edit Google Sheet that **self-heals** back to a pixel portrait of Mikhail Shufutinsky. Edit it; the operator reverts it. | [sheets-operator](https://github.com/sncfoundation/sheets-operator) |
| [DOOM](https://github.com/sncfoundation/sheetdoom) | Real DOOM, run from a container image stored inside a spreadsheet (SICF). | [sheetdoom](https://github.com/sncfoundation/sheetdoom), [sci](https://github.com/sncfoundation/sci) |

More coming. Contributions welcome — a demo is a template + a short README + a link to the live thing.

<sub>Apache-2.0. Do not run production on a spreadsheet. Do run demos on one. It reconciles. 💩</sub>
